# 📚 Study Tracker

Weekly study goals and a daily log for English, Math, Thai, Chinese and Computing,
with progress bars and a "still to finish" list.

## Install

Live page: **https://punyaphat-khan.github.io/study-tracker/**

- **iPad / iPhone:** open the page in **Safari** → tap **Share** → **Add to Home Screen**.
- **Android / Chrome:** tap the **📲 Install App** button.

Works offline after the first open.

## Your data

Your goals and logs are saved **on your device**, inside the app.
The home-screen app keeps its own data, separate from Safari, so install it first
and then always open it from the home screen.

## Updating

Upload the new `index.html`, then change `study-tracker-v1` in `sw.js` to `v2`, `v3`…
so the installed app picks up the update.
